# コンセプト

## 本プロジェクトの立ち位置と方針
* wrap-lighting や valve-harf-lambert 等、一般的に使われる影のパラメータ実装をlilToonに対して簡単に適用できるようにするためのプリセットを提供する。
* 既存のマテリアルにそのまま適用できるよう、ライティングと影の調整以外の機能は提供しない。
* VRChatアバターへの適用を想定し、ワールドに依存せず汎用的に使えるプリセットにする。極力実装の計算式と合うようにパラメータは設計するが、白飛び/黒つぶれするおそれがある場合は調整する。
