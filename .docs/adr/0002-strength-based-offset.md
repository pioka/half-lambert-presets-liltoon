# ADR 0002: hL² 近似の切片オフセットを _ShadowColor から _ShadowStrength へ移す

- ステータス: [ADR 0011](0011-shadow-offset-back-to-shadow-color.md) により置き換え
- 日付: 2026-08-22

## 背景

`Half-Lambert影 汎用 (hL²近似)` は、lilToon の影の閾値パラメータで
hL² = ((N·L + 1) / 2)² のカーブを近似している。

lilToon の影は「境界 (`_ShadowBorder`) と幅 (`_ShadowBlur`) で決まるランプ」と
「影の濃さ (`_ShadowColor` × `_ShadowStrength`)」の組み合わせでしか表現できず、
hL² のような滑らかな2次カーブを厳密に再現することはできない。
そのため本プリセットの `_ShadowBorder` / `_ShadowBlur` / 切片オフセットの3値は、
hL² との誤差が最小になるよう数値最適化によって決めた近似値である。

このうち切片オフセット（影の最暗部を 0 まで落とさず持ち上げる量）は、
これまで `_ShadowColor` をグレー `(0.2895, 0.2895, 0.2895, 1)` にすることで与えていた。

## 決定

切片オフセットの表現を `_ShadowColor` から `_ShadowStrength` に置き換える。

- `_ShadowColor`: `(0.2895, 0.2895, 0.2895, 1)` → `(0, 0, 0, 1)`
- `_ShadowStrength`: `1` → `0.7105`

最暗部の明度は `lerp(1, 0, 0.7105) = 0.2895` となり、従来と数値的に等価である
（0.2895 + 0.7105 = 1）。

## 理由

- 切片オフセットは「影をどれだけ濃くするか」という量であり、意味的には色ではなく強度である。
  `_ShadowStrength` に載せることで、パラメータの意味と実装が一致する。
- `_ShadowColor` が純黒になることで、ユーザーが影に色味（青寄りなど）を付けたい場合に
  オフセット量を壊さずに色だけを変更できる。

## 近似の精度

数値最適化後のパラメータ（`_ShadowBorder` = 0.6907, `_ShadowBlur` = 0.6425,
切片オフセット = 0.2895 相当）における hL² との誤差は以下の通り。

| hL | hL² | プリセットによる近似値 | 誤差 |
| --- | --- | --- | --- |
| 0.00 | 0.000 | 0.068 | +0.068 |
| 0.37 | 0.137 | 0.069 | -0.068 |
| 0.50 | 0.250 | 0.261 | +0.011 |
| 0.70 | 0.490 | 0.557 | +0.067 |

最大誤差は約 ±0.068。最暗部が完全な黒にならない（hL = 0 で 0.068）点と、
中間調がやや明るく出る点が近似の主な特徴である。
実用上は違和感が出ない範囲と判断し、この値を採用する。

## 影響

- 見た目は従来と等価であり、既存ユーザーへの影響はない。
- `_ShadowStrength` は影マスク (`_ShadowStrengthMask`) や他の影段にも効く共通係数のため、
  今後 `_ShadowStrength` を単独で変更すると切片オフセットが意図せず動く点に注意が必要。
