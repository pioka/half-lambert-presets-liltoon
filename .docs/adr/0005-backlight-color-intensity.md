# ADR 0005: 逆光ライトの色を (2, 2, 2) から (1.5, 1.5, 1.5) に下げる

- ステータス: 承認済み
- 日付: 2026-08-22
- 対象: `Presets/half-lambert-with-backlight.asset` の `_BacklightColor`

## 背景

`_BacklightColor` は初回導入以来 `(2, 2, 2, 1)` だった。lilToon の逆光は

```
逆光の寄与 = _BacklightColor × ランプ(_BacklightBorder, _BacklightBlur)
```

として加算されるため、この色の輝度がそのままリムの明るさの倍率になる。
`2.0` は白 (1.0) の 2 倍、Unity の HDR カラーピッカーの表記でいえば
RGB = (1, 1, 1) / Intensity = 1.0（= 2^1 倍）にあたる。

実際に一般的な VRChat ワールドで使用したところ、この強度では逆光が浮いて見え、
周囲のライティングと馴染まないという評価になった。ワールド側の光源に対して
リムだけが常に 2 倍の白で乗るため、暗めのワールドほど不自然さが出る。

## 決定

`_BacklightColor` を `(1.5, 1.5, 1.5, 1)` にする。白に対して 1.5 倍、
[ADR 0001](0001-backlight-parameters.md) で決めた Blur / Border はそのまま据え置く。

強度の調整はこの色の輝度のみで行い、Blur / Border には触れない。両者は
ADR 0001 の式 `_BacklightBorder = 0.5 - _BacklightBlur / 2` で結ばれた
「リムが乗る画面半径」を決めるパラメータであり、そこを動かすと
リムの太さと階調が変わってしまう。今回変えたいのは太さではなく明るさである。

### 「Intensity 1.0 程度」について

Unity の HDR カラーピッカーは格納値を `RGB × 2^Intensity` に分解して表示するため、
格納値 `1.5` は正規化すると RGB = (1, 1, 1) / Intensity ≒ 0.585 と表示される。
本 ADR および要望にある「Intensity 1.0 程度」は、ピッカー上の Intensity スライダーの
値ではなく「白の 1.5 倍という控えめな倍率」を指す。パラメータの真値は
格納値 `1.5` の側であり、ピッカーの表示はその分解にすぎない。

## 影響

- 逆光リムの明るさが従来比 0.75 倍になる。リムの太さ・階調カーブは変わらない。
- 既存マテリアルへの影響はない。プリセットは適用時に値が焼き込まれるため、
  パッケージを更新しても適用済みマテリアルの見た目は変わらない。
  従来の強さを維持したい場合は、マテリアル側で `_BacklightColor` を
  `(2, 2, 2)` のままにしておけばよい。
- 見た目が変わる変更のため、リリースは既存の `0.3.0-dev`（pre-release）に含める。
- より強い逆光が欲しいユーザーは `_BacklightColor` の輝度だけを上げればよく、
  Blur / Border を触る必要がないことを本 ADR で明確にした。
