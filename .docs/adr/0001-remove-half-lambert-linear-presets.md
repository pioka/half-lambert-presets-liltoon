# ADR 0001: 線形 Half-Lambert (hL) プリセットを削除する

- ステータス: 承認済み
- 日付: 2026-08-22

## 背景

本パッケージは当初、Half-Lambert シェーディングの2種類のプリセットを収録していた。

- `Half-Lambert影 汎用 (hL²近似)` — 大抵のマテリアル向けの汎用プリセット
- `Half-Lambert影 半透過 (hL)` — 髪などの半透過オブジェクト向けプリセット

hL は、半透過オブジェクトに hL² を適用すると影が濃くなりすぎるという想定のもとで、
線形の Half-Lambert を用意したものだった。

## 決定

線形 Half-Lambert (hL) のプリセットを削除し、hL² のみを収録する。

対象ファイル:

- `Presets/half-lambert-linear.asset`
- `Presets/half-lambert-linear-backlight.asset`（hL 本体とペアで使う逆光ライトのため併せて削除）

## 理由

- 線形の Half-Lambert では、半透過オブジェクトに適用しても不自然に明るく見えてしまい、
  本来意図していた「半透過向け」という用途を満たせていなかった。
- hL² プリセットを髪に適用しても違和感が出ないことが確認できたため、
  半透過オブジェクト専用のプリセットを別途用意する必要性がなくなった。

## 影響

- 収録プリセットは hL² 系のみとなり、ユーザーはマテリアルの種類を問わず同一のプリセットを適用できる。
- 既存プロジェクトで hL プリセットを適用済みのマテリアルは、プリセットが適用済みの
  プロパティ値としてマテリアルに焼き込まれているため、パッケージ更新によって見た目が変わることはない。
  ただし再適用したい場合は hL² を使う必要がある。
- 破壊的変更のため、バージョンを `0.3.0-dev`（pre-release）に更新した。
