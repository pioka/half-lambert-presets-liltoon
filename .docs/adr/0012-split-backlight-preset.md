# ADR 0012: 逆光ライトを逆光のパラメータだけのプリセットに戻す

- ステータス: 承認済み
- 日付: 2026-09-23
- 置き換え対象: [ADR 0003](0003-merge-backlight-into-shadow-preset.md)

## 背景

[ADR 0003](0003-merge-backlight-into-shadow-preset.md) により、逆光ライトは影と逆光を
まとめて適用する統合プリセット `Half-Lambert影+逆光ライト` として収録されている。
統合プリセットは影のパラメータも上書きするため、影を別の設定にしたまま、あるいは
影の値を調整した後に逆光ライトだけを追加することができない。

## 決定

統合プリセットを廃止し、逆光ライトのパラメータ（`_UseBacklight` と `_Backlight*`）だけを
設定するプリセットにする。影のプリセットは変更しない。

| ファイル | 表示名 | 内容 |
| --- | --- | --- |
| `Presets/half-lambert.asset` | Half-Lambert影 | 影のみ |
| `Presets/half-lambert-backlight.asset` | Half-Lambert影用 逆光ライト | 逆光ライトのみ |

逆光ライトの各プロパティ値は統合プリセットから変更しない。したがって
`Half-Lambert影` → `Half-Lambert影用 逆光ライト` の順に適用した結果は、
統合プリセットを適用した結果と同一になる。

表示名の「Half-Lambert影用」は、逆光の Blur / Border が `Half-Lambert影` の `_ShadowBlur` から
導出されている（[ADR 0001](0001-backlight-parameters.md)）ことを示す。

## 影響

- 逆光ライトを使うには 2 つのプリセットを順に適用する必要がある。手順は README に記載する。
- 逆光プリセットは単独でも適用できてしまう。`Half-Lambert影` 以外の影設定と組み合わせると
  ADR 0001 の前提（逆光の Blur が影の Blur の k 倍）が崩れ、リムの太さや階調が意図と異なる。
- 影の `_ShadowBlur` を変更した場合に逆光の Blur / Border を再計算するという ADR 0001 の制約は、
  再び 2 ファイルにまたがる。
- 既存マテリアルへの影響はない。プリセットは適用時に値がマテリアルへ焼き込まれるため、
  パッケージ更新によって見た目が変わることはない。
- プリセットのファイル名・表示名が変わる破壊的変更である。
