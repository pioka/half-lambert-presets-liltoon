# ADR 0003: 逆光ライトを単体プリセットから「影＋逆光」統合プリセットへ変更する

- ステータス: 承認済み
- 日付: 2026-08-22

## 背景

これまでの収録プリセットは以下の2種類だった。

- `Half-Lambert影 汎用 (hL²近似)` — 影のみを設定するプリセット
- `Half-Lambert影 汎用 (hL²近似) 用 逆光ライト` — 逆光ライトのみを設定し、上記に**重ねて**適用するプリセット

この構成には次の問題があった。

- 逆光ライト単体では意味をなさず、影プリセットを先に適用しているという前提を持つ。
  にもかかわらずプリセット一覧はその依存関係を表現できず、単独で適用できてしまう。
- 逆光のパラメータは影の `_ShadowBlur` から導出される（[ADR 0001](0001-backlight-parameters.md)）。
  すなわち両者は独立に適用可能な直交する設定ではなく、常に対で成立する1つの設定である。
- 「2回適用する」という手順自体が使い方の説明コストになっていた。

## 決定

逆光ライト単体のプリセットを廃止し、影と逆光をまとめて適用する統合プリセットにする。
収録プリセットは以下の2種類とし、ユーザーはどちらか一方だけを適用する。

| ファイル | 表示名 | 内容 |
| --- | --- | --- |
| `Presets/half-lambert.asset` | Half-Lambert影 | 影のみ |
| `Presets/half-lambert-with-backlight.asset` | Half-Lambert影+逆光ライト | 影＋逆光ライト |

統合プリセットのプロパティ値は、従来の2プリセットを順に適用した結果と同一である
（影側・逆光側それぞれの値は変更していない）。

あわせて、線形 Half-Lambert (hL) プリセットが併存していた時期の名残である識別子を削除する。
hL は既に削除されており（[ADR 0001](0001-remove-half-lambert-linear-presets.md)）、
「hL² であること」「汎用であること」を明示して区別すべき相手が存在しないため。

- ファイル名の `squared`: `half-lambert-squared.asset` → `half-lambert.asset`、
  `half-lambert-squared-backlight.asset` → `half-lambert-with-backlight.asset`。
- 表示名の `汎用` / `(hL²近似)`: 「半透過オブジェクト用 (hL)」に対する「汎用 (hL²近似)」という
  対比の片割れであり、対比相手を失った現在は全プリセットが汎用かつ hL² であるため区別に寄与しない。
  シェーディングが hL² であることは README 冒頭の紹介文に一箇所だけ記載する。

## 影響

- 逆光ライトのみを後から追加適用することはできなくなる。
  逆光を付けたい場合は統合プリセットを適用し直す。ただし本プリセット群は
  ライティングと影に関するプロパティしか変更しないため、適用し直しても他の設定は失われない。
- 既存マテリアルへの影響はない。プリセットは適用時に値がマテリアルへ焼き込まれるため、
  パッケージ更新によって見た目が変わることはない。
- 影側の Blur を変更した場合に逆光の Blur / Border を再計算するという ADR 0001 の制約は、
  1ファイル内で完結するようになり守りやすくなった。
- プリセット名・ファイル名が変わる破壊的変更のため、リリースは既存の `0.3.0-dev`
  （pre-release）に含める。
