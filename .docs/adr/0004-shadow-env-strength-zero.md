# ADR 0004: _ShadowEnvStrength を 0 にする

- ステータス: 承認済み
- 日付: 2026-08-22

## 背景

本プリセットは初回コミット (`cd9531d`) 以来、`_ShadowEnvStrength` を `0.2` に設定していた。
lilToon におけるこのプロパティのデフォルト値は `0` であり、意図的に持ち上げていた値である。

`_ShadowEnvStrength` は、影部分に環境光（間接光）の寄与を混ぜ戻す係数である。
すなわち影の明度が、マテリアル自身のパラメータだけでなく
**シーンの環境光に応じて変動する**項を持つことになる。

これが [ADR 0002](0002-strength-based-offset.md) の近似と噛み合わない。
本プリセットの `_ShadowBorder` = 0.6907 / `_ShadowBlur` = 0.6425 /
切片オフセット 0.2895 相当（`_ShadowStrength` = 0.7105）は、影の明度が

```
ランプ(_ShadowBorder, _ShadowBlur) × _ShadowStrength
```

というモデルで決まることを前提に、hL² = ((N·L + 1) / 2)² との誤差が最小になるよう
数値最適化して求めた値である。`_ShadowEnvStrength` が 0 でないと、
このモデルに環境光依存の加算項が乗る。結果として

- 最暗部の明度が、最適化で決めた 0.2895 相当から環境光の量だけ上振れする
- そのずれ幅がワールド／ライティング環境ごとに変わるため、
  ADR 0002 に記載した最大誤差 ±0.068 が保証できなくなる

つまり、近似の精度が**環境依存で不定になる**。

## 決定

両プリセットの `_ShadowEnvStrength` を `0.2` から `0` に変更する。

- `Presets/half-lambert.asset`
- `Presets/half-lambert-with-backlight.asset`

エントリ自体は残し、`value: 0` を明示する。プリセット適用時に
マテリアル側の既存値を必ず 0 で上書きするためであり、
過去に `0.2` が焼き込まれたマテリアルも再適用で確実に是正される。

## 影響

- 影が環境光を拾わなくなり、影の明度は環境を問わず
  ADR 0002 の近似どおり（最暗部 0.2895 相当）に固定される。
- 明るいワールドでは、従来より影がわずかに濃く見える。
  これは hL² 本来のカーブに近づいた結果であり、退行ではない。
- 既存マテリアルはプリセット適用時に値が焼き込まれているため、
  パッケージ更新だけで見た目が変わることはない。改善を反映するには再適用が必要。
- 挙動が変わる変更のため、リリースは既存の `0.3.0-dev`（pre-release）に含める。
