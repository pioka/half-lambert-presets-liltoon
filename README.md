# Half-Lambert Presets for lilToon
[![](https://img.shields.io/badge/Add_to-VCC-%230f91a9)](https://pioka.github.io/vpm-listing/)

Valve が初代 Half-Life で用いた Half-Lambert シェーディング (hL²) を lilToon に移植したプリセット集です。

## 特徴
本プリセットが変更するのは **ライティングと影に関するプロパティのみ** です。
テクスチャ・色・描画モード・アウトラインなどの設定はそのまま残るため、
アバターに元から設定されているマテリアルへ後から適用できます。

明るさに関わる次のプロパティも設定します。

| プロパティ | 値 | 理由 |
| --- | --- | --- |
| `_LightMaxLimit`（明るさの上限） | `1` | 影の濃さがこの値を前提に調整されているため |
| `_LightMinLimit`（明るさの下限） | `0.05` | 暗いワールドでも最低限の明るさを保つため |
| `_BlendOpFA`（ForwardAdd の合成方法） | `0`（Add） | ポイントライト等の追加ライトの合成結果をマテリアルによらず揃えるため |
| `_LightDirectionOverride`（ライト方向のオーバーライド） | 既定の方向 + オブジェクト追従 | ライトがほぼ無いワールドでも、アバターの姿勢によらず同じ面が照らされるようにするため |

これらをマテリアルごとに調整している場合、プリセットを適用すると上書きされます。

また、Half-Lambertの特長として、マテリアルを選ばず共通プリセットとして適用しても違和感が出ません。

## 導入
[このリンク](https://pioka.github.io/vpm-listing/) からVCCにリポジトリを登録し、導入したいプロジェクトに本パッケージを追加してください。
lilToon 2.0.0 以降が必要です。

## 使い方

1. 適用対象のマテリアルを選択し、lilToon のインスペクタを開く
2. 上部の「プリセット」ボタンを押し、プリセット一覧を開く
3. 「その他」カテゴリを開き、下記収録プリセットから適用したいものを選ぶ

※ インストール済みにも関わらず一覧に表示されない場合、「リストを更新」ボタンを押すことでプリセット一覧に表示されるようになります。それでも表示されない場合、lilToonのバージョンが2.0.0以降になっているか改めて確認してください。

## 収録プリセット

| プリセット名 | 用途 |
| --- | --- |
| Half-Lambert影 | Half-Lambert シェーディングを適用するプリセット |
| Half-Lambert影用 逆光ライト | 輪郭に逆光のハイライトを与えるプリセット（逆光ライトの設定のみ） |

逆光ライトが必要な場合は、「Half-Lambert影」を適用した後に「Half-Lambert影用 逆光ライト」を重ねて適用してください。
逆光ライトの輪郭の太さは「Half-Lambert影」の影のぼかしに合わせてあるため、他の影設定と組み合わせると輪郭の太さや階調が意図通りになりません。

## 影の仕組み

影1と影2の2段で Half-Lambert (hL²) の階調を近似します。
`NdotL`（光と面の向きの内積）が 0〜1 の区画を影1が、-1〜0 の区画を影2が担当します。

| | 色 | 範囲 | ぼかし | 担当区画 |
| --- | --- | --- | --- | --- |
| 影1 | グレー（リニア値 `0.25`） | `0.75` | `0.5` | `NdotL` 0〜1（光の当たる側 → 明暗境界） |
| 影2 | 黒 `(0, 0, 0)` | `0.25` | `0.5` | `NdotL` -1〜0（明暗境界 → 真裏） |
| 影3 | オフ | — | — | — |

環境光のない白色光下では、光の正面で `1`、明暗境界 (`NdotL` = 0) で `0.25`、真裏で `0` となり、
その間を直線で結んだ階調になります。これは hL² の値と3点で一致します。

## 影の色について

影の色に関わるプロパティは3つあり、役割が異なります。

| プロパティ | 効く範囲 | プリセット |
| --- | --- | --- |
| `_ShadowColor` | 明暗境界付近の影の色 | 設定する（既定は中立グレー） |
| `_Shadow2ndColor` | 真裏に向かう最暗部の色 | 設定する（黒） |
| `_ShadowBorderColor` | 影の境界だけ | 設定しない（lilToon 既定の橙のまま） |

### 影1の色 — `_ShadowColor`

本プリセットは `_ShadowColor` に中立グレー `(0.5371, 0.5371, 0.5371)` を設定します。
これはリニア値 `0.25` をカラーピッカーの sRGB 表記に直したもので、
**環境光のない白色光下では、明暗境界 (`NdotL` = 0) の色がこの値になります。**
そこから真裏に向かって影2の黒へなだらかにつながります。

肌のマテリアルで影を暖色寄りにするなど、影の色味を変えたい場合はこのプロパティを変更してください。

明るさを保ったまま色相だけを変えるには、**明度ではなく輝度**を保つ必要があります。
Unity のカラーピッカーの `V`（明度）は `max(R, G, B)` にすぎず、`V` を保ったまま
彩度 `S` を上げると影は暗くなります。彩度を上げた分だけ `V` も上げてください。
色を強めすぎると hL² の階調は崩れていきます。

影の色はアルベド（メインカラー）との掛け算で決まるため、元の色に無い色相は出ません。
肌のように元から赤味のある色ではよく効きますが、寒色のマテリアルに暖色を入れても
赤くはならず暗くなるだけです。

### 影境界の色 — `_ShadowBorderColor`

本プリセットは影境界の色 (`_ShadowBorderColor`) を変更しません。
lilToon の既定値は橙 `(1, 0.1, 0)` のため、このプロパティに触れたことのないマテリアルでは
影の境界に橙のグラデーションが乗ります。

- Half-Lambert (hL²) 本来の階調を得たい場合は、`_ShadowBorderColor` を黒 `(0, 0, 0)` に設定してください
- 影の境界にだけ色を差したい場合は、このプロパティで調整してください
  （影全体の色味を変えたい場合は上記の `_ShadowColor` を使ってください）
