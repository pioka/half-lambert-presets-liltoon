# Half-Lambert Presets for lilToon
[![](https://img.shields.io/badge/Add_to-VCC-%230f91a9)](https://pioka.github.io/vpm-listing/)

Valve が初代 Half-Life で用いた Half-Lambert シェーディング (hL²) を lilToon に移植したプリセット集です。

## 特徴
本プリセットが変更するのは **ライティングと影に関するプロパティのみ** です。
テクスチャ・色・描画モード・アウトラインなどの設定はそのまま残るため、
アバターに元から設定されているマテリアルへ後から適用できます。

また、Half-Lambertの特長として、マテリアルを選ばず共通プリセットとして適用しても違和感が出ません。

## 導入
[このリンク](https://pioka.github.io/vpm-listing/) からVCCにリポジトリを登録し、導入したいプロジェクトに本パッケージを追加してください。
lilToon 2.0.0 以降が必要です。

## 使い方

1. 適用対象のマテリアルを選択し、lilToon のインスペクタを開く
2. 上部の「プリセット」ボタンを押し、プリセット一覧を開く
3. 「その他」カテゴリを開き、下記収録プリセットから適用したいものを選ぶ

※ インストール済みにも関わらず一覧に表示されない場合、「リストを更新」ボタンを押すことでプリセット一覧に表示されるようになります。それでも表示されない場合、lilToonのバージョンが2.0.0以降になっているか改めて確認してください。

## 収録プリセット

| プリセット名 | 用途 |
| --- | --- |
| Half-Lambert影 | Half-Lambert シェーディングを適用するプリセット |
| Half-Lambert影+逆光ライト | 上記に加えて、輪郭に逆光のハイライトを与えるプリセット |

どちらか一方を選んで適用してください。逆光ライトが不要なら前者、必要なら後者です。

## 影の色について

影の色に関わるプロパティは2つあり、役割が異なります。

| プロパティ | 効く範囲 | プリセット |
| --- | --- | --- |
| `_ShadowColor` | 影全体 | 設定する（既定は中立グレー） |
| `_ShadowBorderColor` | 影の境界だけ | 設定しない（lilToon 既定の橙のまま） |

### 影全体の色 — `_ShadowColor`

本プリセットは `_ShadowColor` に中立グレー `(0.2895, 0.2895, 0.2895)` を設定します。
これは Half-Lambert (hL²) の階調を再現するために必要な明るさで、
**環境光のない白色光下では、影の最暗部の色がそのままこの値になります。**

肌のマテリアルで影を暖色寄りにするなど、影全体の色味を変えたい場合はこのプロパティを変更してください。
`_ShadowStrength` を触る必要はありません。

明るさを保ったまま色相だけを変えるには、**明度ではなく輝度**を保つ必要があります。
Unity のカラーピッカーの `V`（明度）は `max(R, G, B)` にすぎず、`V` を `0.2895` に保ったまま
彩度 `S` を上げると影は暗くなります。彩度を上げた分だけ `V` も上げてください。

| 彩度 `S` | `V` 固定のときの明るさ (`L*`) | 明るさを保つ `V`（暖色 20°） | 同（寒色 220°） |
| --- | --- | --- | --- |
| 0.0 | 31.4 | 0.2895 | 0.2895 |
| 0.1 | 29.6 | 0.306 | 0.311 |
| 0.2 | 27.9 | 0.324 | 0.335 |
| 0.3 | 26.2 | 0.344 | 0.363 |
| 0.4 | 24.6 | 0.366 | 0.396 |

必要な `V` は色相によって変わります（黄〜緑では低め、`S` = 0.3 で 0.30 前後で足ります）。

そのまま使える値は以下の通りです。いずれも既定のグレーと同じ明るさです。

| 用途 | R | G | B |
| --- | --- | --- | --- |
| 既定（中立） | 0.2895 | 0.2895 | 0.2895 |
| 肌向け・暖色 弱 | 0.324 | 0.281 | 0.259 |
| 肌向け・暖色 中 | 0.344 | 0.275 | 0.241 |
| 寒色 中 | 0.254 | 0.291 | 0.363 |

彩度 0.3 程度までなら hL² の階調は保たれます。それ以上に色を強めると影のカーブが崩れていきます。

影の色はアルベド（メインカラー）との掛け算で決まるため、元の色に無い色相は出ません。
肌のように元から赤味のある色ではよく効きますが、寒色のマテリアルに暖色を入れても
赤くはならず暗くなるだけです。

### 影境界の色 — `_ShadowBorderColor`

本プリセットは影境界の色 (`_ShadowBorderColor`) を変更しません。
lilToon の既定値は橙 `(1, 0.1, 0)` のため、このプロパティに触れたことのないマテリアルでは
影の境界に橙のグラデーションが乗ります。

- Half-Lambert (hL²) 本来の階調を得たい場合は、`_ShadowBorderColor` を黒 `(0, 0, 0)` に設定してください
- 影の境界にだけ色を差したい場合は、このプロパティで調整してください
  （影全体の色味を変えたい場合は上記の `_ShadowColor` を使ってください）
