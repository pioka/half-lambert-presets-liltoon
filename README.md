# Generic PBR-like Preset for lilToon
[![](https://img.shields.io/badge/Add_to-VCC-%230f91a9)](https://pioka.github.io/vpm-listing/)

lilToon 向けの汎用PBR調プリセット集です。
アバターの質感を、PBR（物理ベースレンダリング）に近い自然な陰影に寄せます。

## 特徴

**既存マテリアルに重ねて使える**  
本プリセットが変更するのは **ライティングと影に関するプロパティのみ** です。
テクスチャ・色・描画モード・アウトラインなどの設定はそのまま残るため、
アバターに元から設定されているマテリアルへ後から適用できます。

**ワールドを選ばない**  
影色を完全な黒 (0, 0, 0) にせず、明るいワールドでも暗いワールドでも
陰影が潰れないよう調整しています。ワールドごとの再調整は基本的に不要です。

## 導入
「Add to VCC」ボタンからリポジトリを登録し、プロジェクトにパッケージを追加してください。
lilToon 2.0.0 以降が必要です。

## 使い方

1. 対象のマテリアルを選択し、lilToon のインスペクタを開く
2. 上部の「プリセット」ボタンを押す
3. 「その他」カテゴリを開き、一覧から適用したいプリセットを選ぶ

※ インストール済みにも関わらず一覧に表示されない場合、「リストを更新」ボタンを押すことでプリセット一覧に表示されるようになります。

## 収録プリセット

| プリセット名 | 用途 |
| --- | --- |
| 汎用PBR調プリセット_肌 | 肌 |
| 汎用PBR調プリセット_布地 | 布地 |
| 汎用PBR調プリセット_硬質 | 金属・プラスチックなどの硬質面 |
| 汎用PBR調プリセット_半透過 | 半透過 |

### 一覧にない部位について

明示的なプリセットがない部位は、性質の近いものを流用してください。

| 部位 | 推奨プリセット | 補足 |
| --- | --- | --- |
| 髪 | 半透過 | 陰影を締めたい場合は影の境界を手動で少し下げる |
| 革・エナメル | 硬質 | |
| ゴム・ラバー | 布地 | 光沢を抑えたい場合は反射を弱める |
| 目・口内 | 肌 | |
